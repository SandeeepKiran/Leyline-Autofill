Leyline Autofill: Settings

Everything here is stored only in this browser profile. Leyline Autofill sends it to the AI service (OpenAI or Anthropic) only when you click Autofill. The resume file never goes to the AI.

1. AI model and API key

Use a personal key, not a work key. Only the key for the chosen model is needed.

2. My profile and answer style

Your career facts, story bank and writing rules. Load your "Job Application Answers - AI Prompt" file (.md or .txt). No file yet? Click Generate Template.

3. LinkedIn Details

Short answers that forms ask for: contact details, work authorization per country, notice period, salary. Load your "LinkedIn Details" file (.md or .txt). No file yet? Click Generate Template.

4. Resume file

Attached automatically to resume or CV upload boxes. A PDF works best.
